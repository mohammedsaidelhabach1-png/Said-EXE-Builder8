# Said EXE Builder8

هذا المستودع مخصص لبناء ملف Python إلى تطبيق Windows بصيغة EXE عبر GitHub Actions.

ضع ملف Python الرئيسي في جذر المستودع، ويمكن إضافة `requirements.txt` للمكتبات المطلوبة. عند رفع ملف `.py` أو تشغيل سير العمل يدوياً، يبدأ بناء Windows تلقائياً ويظهر الناتج في قسم **Actions > Artifacts** باسم `SaidEXE-windows`.
